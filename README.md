# Django Web Application

A Django web application with user management and comprehensive pytest testing suite.

## Tech Stack
- **Backend:** Python, Django
- **Testing:** pytest with conftest configuration
- **Package Manager:** Pipenv

## Features
- User authentication and management
- Core application modules
- Comprehensive test coverage with pytest
- Clean project structure following Django best practices

## Getting Started

```bash
# Clone the repository
git clone https://github.com/UzoTammy/NewProject.git
cd NewProject

# Install dependencies
pipenv install

# Run migrations
python manage.py migrate

# Run the development server
python manage.py runserver

# Run tests
pytest
```
